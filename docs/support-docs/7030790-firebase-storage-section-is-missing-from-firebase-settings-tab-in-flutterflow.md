Issue: You are trying to set up Firebase Storage in your FlutterFlow Firebase Settings, but you don't see the Firebase Storage Option (example below).

The Firebase Storage tab is not visible because you have not yet set up storage inside the Firebase Console.

![](https://downloads.intercomcdn.com/i/o/679093035/e6ca7757b96adf52265f9c1c/image.png?expires=1741032900&signature=ba15f5aa131698e42b19fe885eff242ab1ce0d0d41a4f2011eebb5c717a576d5&req=cicuFsB9nYJaFb4f3HP0gJHMx1nhxLJg3ACgGHMiLptB4dT6klGYqbUybURG%0Aj6Q%3D%0A)

#### Solution

1. Select Open Firebase Console from inside your FlutterFlow project

![](https://downloads.intercomcdn.com/i/o/679094297/f0a17a93b89c44411dd28630/image.png?expires=1741032900&signature=2112bc57691bc42dfa80ffc6a3906fb95299d62ddc84354eb777f65fd7934c4e&req=cicuFsB6n4hYFb4f3HP0gDNTZRZLwFXV1sZsf2hOZVHtixrrYBLOrENFYWWh%0Aw04%3D%0A)

2. In the build menu click on Storage

![](https://downloads.intercomcdn.com/i/o/679095334/fc968c452913e30fe7cd2606/image.png?expires=1741032900&signature=8d3718b9c7a1020c625213d73b7649d2375c9c60390a6044099ee4867be8fa71&req=cicuFsB7noJbFb4f3HP0gLWPhDNBi6hSZ%2B%2F%2FS4hIHr%2BoQmqM%2BhA98NAEr0t6%0AZlo%3D%0A)

3. Click Get Started and complete storage setup.

![](https://downloads.intercomcdn.com/i/o/679098645/b662d195d1541fc46b986059/image.png?expires=1741032900&signature=d3a94d2a6b240168c4726e5df4de51a6f6f7a76701a09d69cdbfc8ac4ae094d2&req=cicuFsB2m4VaFb4f3HP0gAOFP3%2BQneRqKXSvwaG%2Ba2hATrocbxkcuQEvZt8n%0A1T8%3D%0A)

After you successfully created your storage bucket, you can go to the FlutterFlow project and see the rules option.

Note: After creating Storage it may take up to an hour for this to reflect in your FlutterFlow project.
