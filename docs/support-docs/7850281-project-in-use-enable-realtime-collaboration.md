Background:

This error appears when the user has not shared the project with the organization

Solution

Head over to the Collaboration settings of the project and turn on the "Share with my organization" option.

​

![](https://downloads.intercomcdn.com/i/o/731671701/bbd0b0efdcbad11aeb70b67b/SCR-20230430-pzaq.png?expires=1741032900&signature=1ec51227a2b65f8060be31c946248ec5a901ac8aded67c9c8b1930832ae6dde0&req=cyMmEM5%2FmoFeFb4f3HP0gJByBPcvL2issHDuLdvovFZYLERemMoyeTCEqnEL%0Aokk%3D%0A)

Additionally, Now that you have shared it with the organization if you want to enable "updated real-time collaboration", Click on this button and enable real-time Collaboration for your project.

​

![](https://downloads.intercomcdn.com/i/o/731673668/2aed69658317173e417b7d39/SCR-20230430-pznt.png?expires=1741032900&signature=0654c8660c32c1433e353b853a46759bb4b231cfb7aefd4f75de4d3c84f5b134&req=cyMmEM59m4dXFb4f3HP0gDOONWzvCKZRBt%2B4N63AcfbovMpyRkYb1pKiQX6m%0AWAI%3D%0A)

After implementing this solution, your team members will be able to make changes to your project in real-time.

The issue was not resolved

If the error persists after following the outlined steps, please report this issue to support via Chat or Email at support@flutterflow.io.
