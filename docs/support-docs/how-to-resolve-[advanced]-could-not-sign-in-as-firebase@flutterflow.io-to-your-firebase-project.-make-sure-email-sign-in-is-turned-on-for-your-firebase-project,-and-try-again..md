# Could not sign in as firebase@flutterflow.io to your Firebase project. Make sure "Email Sign-In" is turned on for your Firebase project, and try again.

​

## How To Resolve

---
![](https://downloads.intercomcdn.com/i/o/684345393/b09a4a9846ff674225b5a8d0/Firebase+Image.png?expires=1741032900&signature=f3df2f62690cf9dfe79737eabf3049dc955eced13a9bc00f9c147ff3e9a2031c&req=cigjFc17nohcFb4f3HP0gBsK6PCIvOJQCcWKO5dKm3xwW%2FAoF%2BJ33n%2FxqMNV%0AQe0%3D%0A)

In Firebase, proceed to Authentication, locate find firebase@flutterflow.io 

On the list of users and go ahead to delete the user from the record that contains firebase@flutterflow.io

Back in the application, the Content Management System (CMS) should be resolved. Upon initial refresh, the user will be regenerated and it will grant view access to all documents.
